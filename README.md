# stackmap

Stack timestamps and map durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/stackmap/

## Install / run

```bash
git clone https://github.com/theworker02/stackmap.git
cd stackmap
node src/cli.js
node --test
```
